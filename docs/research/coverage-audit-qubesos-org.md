# QubesOS org coverage audit — "no path missed" (2026-10-26)

Owner instruction: *"phir se isko REA kar do https://github.com/orgs/QubesOS/repositories
taki koi path se devaite na ho."* This is that re-audit: a fresh, evidence-backed proof
that **every public repo in the QubesOS GitHub org is classified, and every repo we
committed to analyze (Tier B) has evidence + a report.** Generator:
[`audit_repos.py`](qubesos/audit_repos.py) (read-only; deterministic re-run).

## Method (REA Evidence discipline, source-repo route)

REA's routing (and our [00-index](../reverse-engineering/00-index.md) note) applies
repository analysis to complete source repos; binary engines stay for shipped artifacts.
So the audit re-derives everything from two machine-readable sources instead of trusting
prose claims:

1. **Live org listing** — GitHub API `orgs/QubesOS/repos`, 3 pages, fetched 2026-10-26
   (`curl`, unauthenticated snapshot). 215 repos returned.
2. **Published classification** — tier rules lifted **verbatim** from
   [`build_graph.py`](qubesos/build_graph.py) (the generator that produced the original
   16-family / Tier A–D docs), re-run over the live data.

## What "no deviation" means after this audit

- **Nothing new to analyze:** the org has not changed since the research snapshot — the
  25 analyzed targets remain exactly the right set (22 Tier B + 3 classic teaching repos).
- **Nothing silently skipped:** any repo *not* in Tier B carries an explicit tier
  disposition (A = upstream reuse, C = real but deferrable, D = meta) in the manifest;
  tier membership is rule-derived, not judgement-in-prose.
- **Deviation would have been caught by design:** a new org repo, a repo flipping
  fork→source, or a Tier B repo losing its evidence file all make the audit exit non-zero.

## Limitations

- Unauthenticated API snapshot (count + attributes only); per-repo file-level re-analysis
  was not repeated — the existing `evidence/*.txt` files remain the per-repo evidence base
  (generated by `collect_evidence.py`, also reproducible).
- Tier rules are replicated from `build_graph.py` inside `audit_repos.py`; if
  `build_graph.py`'s rules ever change, copy them again (audit prints both sets).
- Archived repos stay classified (11 archived in both snapshots) — history, not drift.
